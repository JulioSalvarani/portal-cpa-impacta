# portal-cpa-impacta
Portal web desenvolvido para a Comissão Própria de Avaliação (CPA) da Faculdade Impacta, centralizando dashboards das pesquisas institucionais, mural de devolutivas e relatórios, com controle de acesso por perfil (aluno, coordenador, administrador e avaliador externo), promovendo transparência e participação da comunidade acadêmica.
